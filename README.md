# 🧠 AI Document Question Answering System

A Retrieval-Augmented Generation (RAG) system that lets users upload documents (PDF/TXT) and ask natural-language questions about their content — answers are generated by a local LLM and grounded strictly in the uploaded document, with no hallucinated content.

Built from scratch to understand every layer of a real-world Generative AI application: document ingestion, chunking, embeddings, vector search, and LLM-based answer generation.

---

## ✨ Features

- 📄 Upload PDF or TXT documents
- ✂️ Automatic chunking with configurable size/overlap
- 🧬 Local embeddings via Ollama (`nomic-embed-text`) — no API costs
- 🔍 Semantic vector search using ChromaDB
- 🤖 Grounded answer generation via a local LLM (`llama3.1`), with explicit anti-hallucination prompting
- 💬 Chat-style interface with conversation history
- ⚡ Fully local — no data leaves your machine

## 🏗️ Architecture

```
┌─────────────┐      ┌──────────────┐      ┌─────────────┐
│  Streamlit  │─────▶│   FastAPI    │─────▶│  ChromaDB   │
│  (frontend) │◀─────│  (backend)   │◀─────│ (vector DB) │
└─────────────┘      └──────┬───────┘      └─────────────┘
                             │
                             ▼
                      ┌─────────────┐
                      │   Ollama    │
                      │ (local LLM) │
                      └─────────────┘
```

**Ingestion flow:** Document → LangChain loader → text chunks (RecursiveCharacterTextSplitter) → embeddings (nomic-embed-text) → stored in ChromaDB

**Query flow:** Question → embedded → semantic search in ChromaDB → top-k relevant chunks retrieved → stuffed into a grounding prompt → LLM (llama3.1) generates the answer

## 🚀 Setup & Running Locally

### Prerequisites
- Python 3.10+
- [Ollama](https://ollama.com) installed

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/ai-document-qa-system.git
cd ai-document-qa-system
```

### 2. Pull the required local models
```bash
ollama pull llama3.1
ollama pull nomic-embed-text
```

### 3. Set up the Python environment
```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS/Linux

pip install -r requirements.txt
```

### 4. Run the backend (Terminal 1)
```bash
uvicorn app.main:app --reload
```
Backend runs at `http://127.0.0.1:8000` — interactive API docs at `http://127.0.0.1:8000/docs`

### 5. Run the frontend (Terminal 2)
```bash
streamlit run streamlit_app.py
```
Opens automatically at `http://localhost:8501`
